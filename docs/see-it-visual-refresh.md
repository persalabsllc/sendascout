Presentation-only changes in `components/see-site.tsx` and `app/see-it.css`. No mission actions, payment logic, pricing configuration, report generation, or database schema changed.

- Landing-page content now grows to 1,660 px instead of 1,200 px, with fluid side gutters.
- The mission choices directly follow the hero. The standalone benefits strip and extra large-screen hero padding were removed.
- Five consistent category cards use contrasting brand colors and icons; only the actual three-step process is numbered.
- Product-page previews show the selected template's real checklist and deliverable counts, not the old generic property illustration.
- Mobile layouts use compact stacked category cards. The decorative homepage image is omitted below 600 px so it does not push the mission choices down the page.
- Buttons, text contrast, focus indicators, reduced-motion behavior, and existing form layouts are preserved or improved.
